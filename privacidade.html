Política de Privacidade

Aplicativo: Pop5 Esteira · Última atualização: 23 de outubro de 2026

1. Quem somos

Pop5 Esteira é o aplicativo de uso interno do Canal Pop5 no YouTube. Ele é operado pelo próprio dono do canal e não é oferecido ao público. Contato: alantaru@gmail.com.

2. Dados acessados

Com a autorização da conta Google do canal, o aplicativo acessa, por meio das APIs do YouTube:

  • YouTube Data API (escopos youtube.upload e youtube.force-ssl): enviar vídeos do canal Pop5 e gerenciar seus metadados, miniaturas, legendas e playlists.
  • YouTube Analytics API (escopo yt-analytics.readonly): ler métricas agregadas de desempenho dos vídeos do próprio canal, como visualizações, retenção e taxa de cliques.

O aplicativo não acessa dados de outros canais, de espectadores individuais, de contatos, de e-mail nem de qualquer outro serviço Google.

3. Como os dados são usados

Os dados são usados exclusivamente para publicar os episódios do Canal Pop5 e para orientar a escolha e a qualidade dos próximos episódios com base nas métricas do próprio canal.

4. Armazenamento e segurança

O token de autorização e as métricas ficam armazenados apenas no servidor privado do canal, com acesso restrito ao operador. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

5. Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Serviços do YouTube e do Google

O aplicativo usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

7. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em permissões da Conta Google. Para pedir a exclusão dos dados guardados pelo aplicativo, escreva para alantaru@gmail.com; os dados são apagados do servidor em até 30 dias.

8. Alterações

Esta política pode ser atualizada; a data no topo indica a versão vigente.
